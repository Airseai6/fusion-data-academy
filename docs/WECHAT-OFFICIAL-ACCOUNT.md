## 3. 自定义菜单

`wechat/menu.json` 已经是可直接创建的结构（3 个一级菜单）：

- **玩一关**
  - 游戏大厅 → `/wechat/`
  - 每日一题 → `/puzzle/digits/`
  - 挑战营 → `/wechat/#follow`
- **领资料**
  - 打印包 → 点击事件 `PRINT_PACK`
  - 20 集目录 → 点击事件 `FUSION_CATALOG`
  - 教师合作 → 点击事件 `COOP`
- **关于**
  - 全部游戏 → `/brain/`
  - 联系我 → 点击事件 `CONTACT`

点击事件需要在后台「自动回复 → 关键词回复」里配置同名 key（PRINT_PACK 等）；如果不想配事件，把 `click` 改成 `view` 指向对应 H5 页面即可。

### 方式 A：后台手动配置（推荐先做）

公众号后台 → 内容与互动 → 自定义菜单 → 按上面的结构添加。链接用当前 Pages 地址，换域名后统一改。

### 方式 B：API 一键创建

需要 `WECHAT_APPID` / `WECHAT_APPSECRET`（不要提交到仓库、不要发聊天里）：

```powershell
$env:WECHAT_APPID = '...'
$env:WECHAT_APPSECRET = '...'
node scripts/wechat-mp.mjs create-menu
node scripts/wechat-mp.mjs get-menu
```

> 没有 appid/secret 就只能后台手动配置；自动回复没有稳定的公开新增 API，建议后台粘贴文案。
