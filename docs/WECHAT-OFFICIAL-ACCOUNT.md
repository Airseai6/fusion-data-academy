   - 联系 → 合作交流 / 关于我

> 菜单点击事件需要后台配同名关键词回复；没有配的话点了没反应。

## 1. 菜单点击回复（后台配）

| key | 回复 |
|---|---|
| `PLAY_TODAY` | 今天的题 + 公众号文章链接（国内域名） |
| `PLAY_ALL` | 游戏入口 + 国内备案域名 |
| `FEATURED` | 最近文章链接 |
| `FUSION_CATALOG` | 20 集目录（公众号文章或国内域名） |
| `COOP` | 教师/机构合作说明，回复城市+机构 |
| `ABOUT` | 账号/作者介绍 |
| `PRINT_PACK` | 打印包入口或“本周发”说明 |

**暂时没有国内域名怎么办？**

- 先不要放任何游戏外链；
- 菜单只保留 `click`，回复“入口整理中，先关注/菜单开始”；
- 等域名备案后，把 `{{GAME_HUB_URL}}` 等占位符统一替换。
