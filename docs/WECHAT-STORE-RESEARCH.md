# 微信小店能不能卖电子产品？我能不能开？

> 调研日期：2026-10-28。规则会变，最终以微信小店后台和官方客服为准。

## 结论

1. **能卖电子产品，但不是“有微信号就能卖”。**
   微信小店当前开店流程要求 **营业执照（个体工商户/企业）**；纯个人只有实名微信号，不能走“个体店/企业店”的开店流程。
2. **电子产品不是一个统一类目。**
   要落到 `数码 / 电脑办公 / 手机通讯` 下具体二三级类目；很多是“定向准入/特殊类目”，需要：
   - 3C 强制认证（CCC）；
   - 电信设备进网许可 / SRRC 型号核准（按产品）；
   - 品牌授权/商标资质；
   - 质检报告、进口报关单（进口商品）；
   - 类目保证金（不同类目不同，电子教育新类目 5,000 元起）。
3. **你有营业执照（个体户/企业）→ 可以申请开店；没有 → 暂时不能开微信小店。**
   即使有执照，电子产品的资质/售后/库存也比卖内容/教具重，审核不保证通过。

## 官方依据

- 开店流程：个体店/企业店需要营业执照、经营者/法人身份证、结算账户等；审核 1–3 个工作日。
  https://store.weixin.qq.com/chengzhang/article/wiki?docid=1959&nonce=c9ee93403a7920ba&category_key=growth_center_manual_for_store
- 数码/电脑办公/手机通讯类目管理规则：定向准入；商品需要 3C、进网许可、SRRC、质检报告、品牌/进口资质等；需缴保证金。
  https://store.weixin.qq.com/chengzhang/webdoc/wiki/1067/10a4b3f16b6ffc0c/growth_center_rule_for_store
- 2026-01-20 新增数码开放类目（电子教育：学习机、学习手写板、错题打印机、智能练字笔、口算机等），个体工商户/企业店保证金 5,000 元。
  https://store.weixin.qq.com/chengzhang/webdoc/wiki/8817/2bfcc2b25642b158/growth_center_platform_notice/1

## 对你的业务，更现实的建议

| 方向 | 是否推荐 | 原因 |
|---|---|---|
| 自己进货卖学习机/点读笔/错题打印机 | 谨慎 | 需要 3C/品牌授权/售后/库存，5,000 元起保证金，重资产 |
| 卖打印版游戏包、教具、卡片、书 | 推荐 | 和现有 6–12 岁数学游戏受众匹配，轻库存、易发货 |
| 卖课程/训练营 | 推荐 | 走公众号/知识星球/微信小店（虚拟商品规则另查），不需要电子资质 |
| 做电子产品带货（优选联盟/视频号橱窗） | 可试 | 不压库存，但需要选品和佣金，售后由商家承担 |

## 如果你要开微信小店

1. 办个体工商户/企业营业执照（若没有）；
2. 微信搜索「微信小店开店」或电脑打开 `store.weixin.qq.com/shop`；
3. 选主体类型：个体户/企业；
4. 选类目：不要先选“数码”，先从低风险类目（如图书/文具/教具/日用）起步；
5. 如果要卖电子教育产品：准备 3C、品牌授权、质检报告，缴 5,000 元类目保证金，提交审核；
6. 先小额测试供应链和售后，再扩类目。

## 不该做的事

- 不要把“个人微信”当成“个体店”去提交；
- 不要借别人的营业执照/品牌授权；
- 不要卖无 3C 的电子产品、山寨/破解设备、偷拍/监听类设备（平台禁售）；
- 不要虚假宣传“原装/官方正品/全网最低”。
