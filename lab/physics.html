背后的物理

两个轻核要发生聚变，必须克服库仑势垒。经典力学要求粒子动能超过势垒高度（D-T 约 0.4 MeV）， 但恒星核心只有 keV 量级——远低于这个值。隧穿效应让反应在"能量不够"时仍以极低概率发生。

// Gamow 因子：隧穿概率随能量的变化 P(E) ∝ exp(−√(E_G / E)) // Gamow 能量（D-T 情形，b ≈ 34.4 keV^½） E_G = (π α Z₁Z₂)² · 2μc²

关键性质：温度每升高一点，概率不是线性增长，而是指数级增长。 从 1 keV 到 100 keV，隧穿概率跨越约 13 个数量级。

反应率参数化

本页反应率采用 Bosch–Hale (1992) 的经典参数化，在 0.2–100 keV 区间精度优于 0.25%：

⟨σv⟩ = C₁θ √( ξ / (m_r c² T³) ) · exp(−3ξ) ξ = ( B_G² / (4θ) )^(1/3) θ = T / [ 1 − T(C₂ + T(C₄ + T·C₆)) / (1 + T(C₃ + T(C₅ + T·C₇))) ]

D-T 系数：B_G = 34.3827 keV^½，m_r c² = 1124656 keV。
参考值：T = 10 keV 时 ⟨σv⟩ ≈ 1.1×10⁻¹⁶ cm³/s。

劳森判据

1955 年，J. D. Lawson 在 Harwell 写了一份报告，首次给出了"净能量输出需要什么条件"的定量答案。 今天的聚变装置设计，基本都在回答同一个问题。

// 三重积判据（D-T，点火条件量级） n · T · τ_E ≥ 3×10²¹ keV·s/m³ // 更严格地说，它来自功率平衡： P_α + P_ext = P_loss P_fusion = ¼ n² ⟨σv⟩ E_fus V

为什么是"乘积"

三个量各管一件事，缺一不可：

  • 密度 n — 决定粒子多久撞一次

  • 温度 T — 决定撞上之后能不能"穿墙"
  • 约束时间 τ_E — 决定这份热量能留住多久

而实际装置里，这三个量会互相制约：密度推高，约束往往变差； 温度推高，辐射损失增长更快。这正是设计的难点。
